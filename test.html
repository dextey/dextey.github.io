Technique — Sticky Pin

One pinned element.
Three different views.

This container is position: sticky. As you scroll through 300vh of height, the content inside swaps out. The element never moves — only its children change.

State 2 of 3

Background shifts.
Text morphs.

Each "state" is an absolutely positioned child that fades in/out based on scroll progress. The background color transitions too — all within the same sticky container.

State 3 of 3

Same div.
Completely different feel.

This is how Apple, Linear, and Stripe build those "scroll through features" sections. One pinned box, N states driven by scroll position.
