Project — 01

Flix
A Better Netflix Clone

Flix is a Netflix-inspired streaming interface built using React and Firebase. Users can sign up, browse trending content, and watch trailers of popular movies and TV shows using data from the MovieDB API.

The application focuses on recreating a modern streaming experience using component-based UI design, authentication systems, and dynamic data rendering.

Project — 02

DOPE
Productivity Meets Mindfulness

DOPE is a mobile application built to improve productivity and mental clarity. It combines a task manager, productivity tracker, and meditation system into a single minimal interface.

The goal is to help users manage daily work, build consistent habits, and maintain mental balance while staying productive.

Project — 03

Fakey
Blockchain Powered Authenticity

Fakey is a decentralized e-commerce DApp designed to combat counterfeit products in online markets. It allows users to verify product authenticity through blockchain-based verification.

Live Demo: https://fakey.netlify.app/ — Make sure MetaMask is installed and your wallet is connected to the Polygon Mumbai testnet.
